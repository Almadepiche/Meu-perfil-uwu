# 🌷 Dolly Perfil 🌷

Esse é meu projetinho pessoal em HTML e CSS para treinar desenvolvimento front-end!  
Sou a Dolly, uma baby dev front-end, e esse é o meu cantinho! 🧸🍓

---

## 🧠 O que foi feito até agora:

### ✅ Estrutura HTML

- Criada a estrutura básica HTML (`<html>`, `<head>`, `<body>`).
- Adicionados metadados para:
  - Codificação UTF-8 (acentuação e símbolos).
  - Responsividade com `viewport`.
- Título com fonte estilizada para aparecer na aba do navegador.
- Conteúdo principal:
  - Título com fontes decoradas.
  - Parágrafo de apresentação.
  - Imagem fofa representando a Dolly.
  - Lista com hobbies e interesses.
  - Link para o Pinterest da Dolly.

---

### 🎨 Estilização com CSS

- Criado o arquivo `style.css` e linkado ao HTML.
- Estilo com foco em:
  - Fonte fofa (`Cherry Bomb One`, via Google Fonts).
  - Cores em tons pastéis (rosa, lilás, branco).
  - Centralização do conteúdo.
  - Bordinhas arredondadas, sombras suaves e destaque para áreas como o player de áudio.

---

### 🎵 Player de música

- Música Lo-fi adicionada usando a tag `<audio>` com as opções:
  - `controls`: exibe os controles para o usuário.
  - `autoplay`: começa a tocar automaticamente.
  - `loop`: reinicia automaticamente quando termina.
- O player foi colocado dentro de uma caixinha fofa com borda tracejada e sombra.

> A música usada é **de domínio público**, baixada do Pixabay.
